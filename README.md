# SPREAD

**SPREAD** is an agent-based disease transmission simulator developed as part of  
**CSE 4550 – Simulation and Modeling Lab**.

The project visualizes stochastic disease spread using randomly moving agents and
allows real-time player intervention to contain outbreaks.

---

## 🎮 Concept

- Each dot represents an individual agent
- Agents move randomly (stochastic motion)
- Infection spreads probabilistically upon contact
- The player acts as a **doctor** to cure infected agents

---

## 🧠 Simulation Features

- Agent-based stochastic modeling
- Probabilistic infection transmission
- Random initial conditions
- Non-deterministic outcomes per run

---

## 🕹️ Gameplay Mechanics

- Click to cure infected agents
- Control difficulty through agent speed
- Win/Loss based on infection ratio over time

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Framework:** Pygame
- **Math & Randomness:** Python `math` and `random`
- **Version Control:** Git & GitHub
- **Assets:** Piskel (art), Bfxr (sound)
